Step 1
Upload → Chunk → Embed
Drop any file and the platform handles the rest automatically — chunking, storage in GCS, and vector embedding via Gemini. Documents move through a clear status pipeline you can watch in real time.
⬆PDF, DOCX, CSV, images, TXT — drag-and-drop or click to upload
✂Auto-chunked into 350-word windows with 60-word overlap, stored in GCS
⚡One-click embedding — Gemini generates 768-dim vectors, stored in pgvector
↻Error recovery — Retry button re-downloads from GCS and re-runs the full pipeline

📚Persistent chat sessions — history saved, searchable, resumable

Tags, Search & Sort

🔍Live name search — filters the list as you type, no page reload
⇅Sort by date, name, size, or status — combined with tag filter
🗄Tags stored per-user in PostgreSQL — persist across sessions and devices
