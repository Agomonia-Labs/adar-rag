Step 1
Upload → Classify → Embed
Drop any file and the platform handles the rest automatically — extraction, optional PII redaction, document classification, language detection, chunking, GCS storage, and vector embedding via Gemini.
⬆PDF, DOCX, CSV, images, TXT — drag-and-drop or click to upload
✂Auto-chunked into 350-word windows with 60-word overlap, stored in GCS
🔒PII redaction before chunking and embedding — emails, phones, SSNs, cards, DOB, bank IDs, IPs
🌐Detects document type and language — English, Spanish, Bengali, Hindi, Arabic
⚡One-click embedding — Gemini generates 768-dim vectors, stored in pgvector
↻Error recovery — Retry button re-downloads from GCS and re-runs the full pipeline

Step 2
Voice + Semantic Chat
Ask by typing or speaking in English, Spanish, Bengali, Hindi, Arabic, or the language of the document. Privacy mode can redact PII from the question, chat history, retrieved context, trace previews, and source previews before model use.
🎙Spanish microphone input — Web Speech where available, Gemini audio transcription fallback everywhere else
🔒PII privacy toggle — masks structured identifiers even when OCR inserts spaces
🔍Hybrid search — RRF fusion of vector + BM25, then Gemini re-ranking
💬Streaming responses with markdown, tables, and source citations
🌐Response language follows the document while preserving exact names, dates, and citations
📚Persistent sessions, feedback, evaluation, and exportable chat history

Step 3
Horizontal RAG, Vertical Agentic AI
DocIntel combines self-service RAG with vertical agentic workflows for healthcare, lease management, and restaurants. Users can record long conversations, save transcripts, extract structured domain data, approve outputs, and ask cited questions from one governed workspace.
↔Horizontal RAG — upload, OCR, PII redaction, chunking, embeddings, hybrid search, rerank, citations, 5-language voice/chat, traces
🎙Clinical scribe — consent, record/upload visit audio, transcript, SOAP note draft, patient summary, follow-up checklist, AVS, PHI/quality flags
🏥Clinical agents — patient context, clinical summary, labs, medications, follow-ups, care gaps, and risk flags
🧾Prior authorization agents — payer criteria, evidence mapping, missing documentation, submission risks, and review packet
📄Patient-ready AVS PDF — generated from scribe output, saved to GCS, chunked, embedded, and searchable
🍽Restaurant scribe — segmented long recordings, full transcript, menu/profile extraction, deterministic item-price parsing, edit/approve/save, menu search and price comparison
💬Chat answers questions like: criteria met, evidence available, missing docs, submission risks, and next action
⚙Workflow — JSON orchestrator, subagents, tools, persisted outputs, RBAC review, field audit, evaluation gate, and human approval
👥Useful for patients, caregivers, clinicians, prior auth teams, lease teams, restaurant owners, operations teams, and compliance reviewers

Security & Ops
Admin, Audit & Traceability
For serious document AI, the final answer is not enough. Teams need privacy, traceability, and proof: what was redacted, which sources were used, what prompt was sent, what tools ran, and where an error happened.
📧Email verification — all new accounts verify before first login
🔍Audit log — every upload, login, invite, and delete logged with IP and timestamp
🔒PII redaction — upload-time and runtime privacy modes for chunks, chat, summaries, and traces
🧭Trace viewer — select a question to inspect spans, retrieved chunks, prompts, and LLM/tool events
🧩How it works — X-Trace-Id links trace flows, spans, and LLM events for one question
🔔Email notifications — embedding complete, workspace invite, password reset
